A deadlock fix and the logging a wider release needs.

**Fixes**
- Switching a provider off could freeze the helper for good: it waited for the host's last status line while holding the lock that line needed. Every later click in the window then waited forever, and the provider could not be switched back on. The helper now never waits on a host's output while holding that lock, and a wait that could still stall is capped at two seconds.
- The Corsair host no longer logs "iCUE not reachable" while it is the one disconnecting.
- A second helper instance logs that another is already running instead of exiting silently.

**Logs**
- The helper logs its environment at startup: Windows and .NET versions, edition and install folder, the Razer Chroma Broadcast API version, session and user.
- Every change made in the window is logged in plain words ("corsair off; asus gamma 1 -> 2"), hosts are logged when they are told to stop and how long they took, and a request that takes two seconds or more to answer is logged as a warning.
- Sleep and wake are logged, with how long the PC slept.
- Each host logs when Razer's frames stop for ten seconds and when they resume, and when Razer sends only black and when color returns.
- **Verbose logging**, a new switch at the bottom of the window, adds every request from the window, every settings push to a host, host state changes, and the frame and write rates once a minute. The **Open logs** button beside it shows the log folder.
