Hardening and cleanup after a full review.

**Security**
- The helper refuses a data folder it did not create or that administrators do not own, and never applies permissions through a junction or symbolic link.
- The logon task definition is written inside the administrator-only data folder, not the temp folder, and the task is registered for the logged-in user even when another account provided the elevation.
- The managed OpenRGB's SDK port listens on this PC only.
- The updater also pins the root that issues Azure Artifact Signing certificates, and caps the download by bytes received.

**Fixes**
- A host's reason for stopping is no longer lost to a race, so the window shows it.
- A device toggle no longer stalls the window while a host restarts.
- A host that fails for a reason other than a lost device says why while it reconnects.
- Settings with malformed entries are cleaned on load instead of breaking every later change.
- The helper no longer starts OpenRGB while shutting down.
- Full-to-Full upgrades remove the previous bundled archives; uninstalling removes the HKCU Run entry for the right user and asks whether to remove settings and logs.
- A missing OpenRGB detector list is a hard error instead of silently turning no detectors off.

**Performance and logs**
- OpenRGB devices get every other Chroma frame, which cuts OpenRGB's own CPU use nearly in half; effects look the same.
- OpenRGB's "device list changed" and "connection lost" reconnect at once and are logged as information, not as write failures.
- The Corsair host logs iCUE's reachability when it changes, not every retry; a sleeping PC no longer fills the log.
- The "only black" hint also covers a tile that stays dark after the PC wakes: restart Razer Synapse.

**Project**
- Releases are published only once both installers are attached; a CI build runs on every push.
- README renamed, issue template added, editor settings trimmed to this repository.
