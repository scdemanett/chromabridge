The update that would not install on a slow stop.

**Fixes**
- The installer waited a fixed six seconds after asking the helper to stop. When the helper took longer, because a host was still handing a vendor's lighting back, the silent install found the helper's files in use and quietly aborted, leaving the old version in place. It now waits until the helper and its hosts have exited, up to 45 seconds, and ends them if they still have not.
- The updater runs the installer with a log of its own, `setup-installer.log` in the log folder, so an install that fails leaves a trace.
